# Save Every Memory website starter

This is a responsive static website prototype for review. Open `index.html` in a browser.

## Included
- Responsive homepage and service overview
- Approved digitization price tables
- Interactive estimate calculator:
  - VHS / VHS-C: $19.99 per tape
  - Hi-8 / MiniDV: $24.99 per tape
  - Super 8 / Regular 8 / 16mm silent film: $0.49 per foot
  - Film with sound: $0.85 per foot
  - Photo scanning tier pricing
  - 35mm slides and negatives share a combined tier count
  - One $17.99 flash drive per order (toggleable)
  - 7.25% tax
- Custom quote prompts for all unpriced services
- Quote form UI (not yet connected to email/database)

## Before launch
1. The supplied original Save Every Memory logo is included at `assets/save-every-memory-logo.png`.
2. Replace sample stock photography with approved Save Every Memory project photos/videos.
3. Connect the quote form to a secure backend/email service and test delivery.
4. Confirm the business contact details and tax treatment/rate with the business/accountant.
5. Add privacy policy, terms, accessibility review, SEO metadata and analytics as desired.
6. Test the production build and connect the domain only after approval. Keep existing GoDaddy email DNS records intact during DNS migration.

The existing GoDaddy website and domain are not changed by this prototype.
